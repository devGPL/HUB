GPLHUB ACESSO RESTRITO

Conecte sua conta do GitHub

O HUB lê os repositórios da devGPL direto da API do GitHub, usando um token seu. O token fica salvo só neste navegador e nunca sai dele para outro lugar.

  1. 01
    Crie um fine-grained token com dono devGPL, acesso a todos os repositórios e permissões de leitura em Contents, Pull requests e Metadata. Criar token no GitHub
  2. 02
    Se a org pedir aprovação, aguarde um admin liberar. Se ela não aceitar fine-grained, use um token classic com escopo repo.
  3. 03
    Cole o token abaixo.
